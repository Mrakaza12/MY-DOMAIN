Keyline

A small, honest sign-in app

Keyline creates real accounts: your email and a salted scrypt password hash go into PostgreSQL, and a signed-in session lives in an httpOnly cookie. Nothing else is collected.

  • Sign up, sign in and sign out
  • Passwords hashed with scrypt — never stored in plain text
  • A dashboard showing your own recent sign-in activity

The application is a Next.js server with a database, so it runs on Vercel rather than GitHub Pages. This page is only the project introduction — deployment takes about five minutes and is described in DEPLOY.md.
